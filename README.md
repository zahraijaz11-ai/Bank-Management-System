# 🏦 Bank Management System

A console-based **Bank Management System** developed in **Python** using **Object-Oriented Programming (OOP)** principles. This application allows users to create and manage bank accounts, perform transactions, and view account details through a menu-driven interface.

---

## 📌 Features

- Create new customer accounts at runtime
- Select existing accounts
- Deposit money
- Withdraw money
- Check account balance
- View transaction history
- Support for multiple customer accounts
- Unique Customer IDs and Account Numbers
- Input validation and exception handling
- Menu-driven interface

---

## 🛠️ Technologies Used

- Python 3
- Object-Oriented Programming (OOP)
